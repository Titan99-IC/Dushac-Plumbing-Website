## Design Philosophy
Modern industrial contractor aesthetic. Strong typography, authentic project photography, clean grids, restrained palette (deep navy/slate, copper/rust, off-white, neutral grays). No generic stock photos, patterns, or excessive decoration. Communicate: family-owned + technical capability + established history + multi-service expertise.
